TGO Análisis y Desarrollo de Software

01_Child >

Creates child elemenets (nesting)

Example

ul>li>a ↔️

Result:

<ul> <li> <a href="" ></a> </li> </ul>

02_Sibling

Creates sibling elemenets (nesting)

Example

header+section+footer ↔️

Result:

<header></header> <section></section> <footer></footer>

03-Multiplication *

Repeats elements multiple times.

Example

div.contenedor↔️

Result:

<div class="contenedor"></div>

04-class

Creates a class attribute.

Examples

div.important↔️

danger↔️

Result:

<div class="important"></div> <div class="danger"></div>

05-Classes ...

Creates multiples class attribute.

Examples

div.red.green.blue ↔️

Result:

<div class="red green blue"></div>

06-identificacion #

Creates an ID attribute.

Examples

menu#cod123 ↔️

Result:

<menu id="cod123"></menu>

07-Text {}

Inserts text content.

Examples:

p{Lorem Ipsum Dolor} ↔️

a{Click Aquí} ↔️

Result:

<p>Lorem Ipsum Dolor</p> <a href="">Click Aquí</a>

08-Custom Attribute []

Creates custom attributes.

Example:

input[type=number] ↔️

Result:

<input type="number">

09-Item Numbering $

Adds consecutive numbers.

Examples:

ul>li.option$$*3 ↔️

Result:

<ul> <li class="option01"></li> <li class="option02"></li> <li class="option03"></li> </ul>

10-Reverse Numbering @-

Inverts numbering order.

Example:

iul>li.num$@-*3 ↔️

Result:

<iul> <li class="num3"></li> <li class="num2"></li> <li class="num1"></li> </iul>

11-Base Numbering @n

Defines a base number for sequences.

Example:

ul>li.num$@3*4 ↔️

Result:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb Up ^

Moves up one level.

Example:

section>article>div^p ↔️

Result:

<section> <article> <div></div> </article> <p></p> </section>

13-Grouping ()

Groups elements together.

Example:

(header>nav)+(section>article) ↔️

Result:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem lorem

Generates placeholder text.

Examples:

lorem3 ↔️

lorem20 ↔️

lorem*5 ↔️

Result:

Lorem, ipsum dolor.

15-HTML Documents html:

Creates various HTML document types.

Examples :

html:xs ↔️

html:xt ↔️

html:4s ↔️

html:4t ↔️

html:5 ↔️

Result:

<html:xs></html:xs> <html:xt></html:xt> <html:4s></html:4s> <html:4t></html:4t>

16-Meta Tags meta:

Generates meta tags.

Example :

meta:vp ↔️

Result:

<meta name="viewport" content="width=device-width, initial-scale=1.0">
