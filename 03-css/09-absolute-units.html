09-Absolute Units

Specify a fixed length value. It doesn't matter if the screen's width or height changes.

  • Inch (in)
  • Centimeter (cm)
  • Milimeter (mm)
  • Point (pt)
  • Picas (pc)

Examples:

  • Inch: 0.4in
  • Centimeter: 1cm
  • Milimeter: 10mm
  • Point: 10pt
  • Picas: 15pc
